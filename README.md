Personal Portfolio — Ayoub Kourdini
Project Overview

This project is a personal portfolio website developed as part of my Web and Web Mobile Developer training.

Starting from an existing HTML5/CSS3 template and its Figma mockup, I customized the design and content, reorganized the website into five separate pages, and developed a dedicated About page.

The purpose of this portfolio is to present my background, technical skills, projects, and professional goals through a clear and structured website.

Website Pages

The portfolio consists of five interconnected pages:

Page	File	Description
Home	index.html	Personal introduction and presentation
About	a-propos.html	Background and professional goals
Skills	competences.html	Technical skills and areas of expertise
Projects	projets.html	Projects, descriptions, technologies, and links
Contact	contact.html	Contact form and professional links

All pages share the same header, navigation menu, footer, and external CSS stylesheet to maintain a consistent design.

Technologies Used
HTML5 — Semantic structure and content.
CSS3 — Styling, custom properties, and page layouts.
Flexbox — Flexible alignment and layout.
CSS Grid — Structured project card layouts.
Figma — Interface design and mockup customization.
Git — Version control.
GitHub — Source code hosting and project publication.
W3C Validator — HTML validation.
Design and Customization

The original template was adapted to create a personalized visual identity.

The main improvements include:

Replacing generic content with personal information.
Customizing the color palette and typography.
Defining reusable CSS variables for colors and fonts.
Organizing projects into a grid layout.
Creating a dedicated About page.
Providing a separate Skills page.
Improving navigation between all five pages.
Completing the contact form with appropriate field types, labels, and required attributes.

Installation

Clone the repository:

git clone https://github.com/ayoubkourdini/starter-portfolio.git


Navigate to the project directory:

cd starter-portfolio


Open index.html in your browser to view the website.

No additional dependencies or build tools are required.

Validation and Code Quality

The project aims to follow HTML5 and CSS3 best practices, including:

Semantic HTML elements.
One main heading (h1) per page.
A logical heading hierarchy.
Alternative text for images.
Labels associated with form fields.
Appropriate input types and required attributes.
A shared external stylesheet.
Reusable CSS variables.
HTML validation using the W3C Markup Validation Service.
Learning Objectives

Through this project, I am developing practical skills in:

Modifying and improving an existing codebase.
Translating a Figma mockup into HTML and CSS.
Creating and linking multiple web pages.
Reusing CSS styles and layout components.
Building layouts with Flexbox and CSS Grid.
Managing source code with Git and GitHub.
Validating HTML and maintaining code quality.
